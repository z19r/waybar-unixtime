The current unix timestamp, ticking in your Waybar.

A single Rust binary for Hyprland rice. Click for a dropdown of 15 formats — seconds to nanoseconds, ISO to Japanese — each one copy-on-click. It repaints itself from whatever omarchy theme you're running.

features

live stream, not a script

Continuous exec mode: one process prints a JSON line per tick. No shell, no date(1) forked every second.

dropdown of every format

Left-click opens a menu: s / ms / µs / ns, ISO 8601 ×3, European, US, British, Japanese, RFC 2822. Click = copied.

display what you want

Right-click toggles s ⇄ ms. waybar-unixtime set iso-utc — or any custom strftime — changes the bar text itself.

omarchy-native themes

Reads the active theme's colors.toml and generates namespaced waybar CSS. Switch themes, module follows.

tooltip that answers

Hover shows the whole panel — every format with its live value. Stop alt-tabbing to a converter site.

picker for the rest

Right-click: a walker dmenu with a date⇄epoch converter (offsets like now +2h30m) and your copy history.

custom formats + settings

Name your own strftime patterns in config.toml — they join the dropdown, tooltip, and picker. History size too.

tiny and honest

Rust, MIT licensed, no runtime deps, prebuilt binaries with checksums. Read all of it in one sitting.

the dropdown

This is the click menu, live. Every row is the real value right now — click one to copy it.

install

# cargo
cargo install waybar-unixtime
# arch, the honest way
git clone \
  https://github.com/z19r/waybar-unixtime
cd waybar-unixtime/packaging/aur
makepkg -si
# waybar config.jsonc
"custom/unixtime": {
  "exec": "waybar-unixtime",
  "return-type": "json",
  "restart-interval": 1,
  "on-click": "waybar-unixtime copy | wl-copy",
  "on-click-right": "pkill -USR1 -x waybar-unixtime"
}

theming

One command reads ~/.config/omarchy/current/theme/colors.toml and writes namespaced CSS. This page is doing the same trick — hit the theme buttons above.

# generate + install for the active theme
waybar-unixtime css --install
/* generated: unixtime.css */
@define-color unixtime-accent #c9a554;
@define-color unixtime-fg     #c2c2b0;
@define-color unixtime-bg     #16161c;

#custom-unixtime { color: @unixtime-fg; }
#custom-unixtime.millis { color: @unixtime-accent; }
